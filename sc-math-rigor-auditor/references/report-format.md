# SC 严谨性审查报告格式

预设档名为 `rigor_reviews/rigor_SC_<来源档名主体>.vN.md`（例如审查 `ch02.ipynb` 得到 `rigor_SC_ch02.v1.md`），N 取既有最高版本加 1。与 TC 报告 `rigor_TC_*.md` 分开命名。未指定落盘且仅问单句时，可直接在对话中提供同等证据，不必建立报告档。报告使用简体中文。

## 报告开头

记录：

- 审查日期、目标 SC 档案与对应 TC 档案、来源 commit（无 git 时说明）、工作区修改状态、两者实际读取文件字节的完整 SHA-256（Windows 检出可能是 CRLF，按实际读取的字节计算）。
- 审查语言（SC）、涵盖章节及 cell 范围；SC 与 TC 的 cell 数与对齐情况；已阅读的前置定义、相关章节、已引用的 TC 报告（档名与版本、其指纹是否仍为现行 TC）与明确未查范围。
- 主审与复核方式；只有实际可知的模型名称才填写，不臆测版本。
- 验证工具与实际执行状态；独立复核状态：未做／完成／部分完成。

## 统计摘要

按最终条目字段计算，分两个维度列出：

| 根因来源 ＼ 影响 | high | medium | low |
|---|---|---|---|
| inherited_from_tc | | | |
| conversion_error | | | |
| sc_only_edit | | | |
| undetermined | | | |

另注明其中属于规则性转换错误（建议修 converter）的条目数。

## 范围覆盖表

| 小节或完整论证 | cell／label | 检查结果 | 限制 |
|---|---|---|---|

结果使用「已审，有发现」「已审，未发现问题」「部分已审」「未审」。没有发现不是形式化证明的正确性保证；不提供没有依据的正确率。

## 发现清单

依影响排序，每笔使用稳定 id（格式 `rigor-sc-<来源档名主体>-NNN`，例如 `rigor-sc-ch02-001`，与 TC 报告的 `rigor-tc-<来源档名主体>-NNN` 对应）。同一根因的多处出现合并列位置，避免重复计数（例如同一条 converter 规则造成的多处行/列误调合为一笔，列出全部位置）。重审沿用已有 id，新问题追加 id。

每笔包含：

1. **类型／影响／判断／根因来源**：使用 SKILL.md 的分类。
2. **定位**：SC 档案、§章节、0-based cell index、cell id（若有）、label（若有）、1-based cell 内行号；并列出对应 TC 位置。不存在的字段写「无」，不可杜撰。
3. **原文**：SC 精确节录与对应 TC 原句，保留公式及必要前后文。凡涉及行/列，SC 与 TC 两侧都在引文后标注英文 row/column 语义（例：SC「第 2 行」（row 2）；TC 原文「第 2 列」（= row 2）），并写出所依据的公式或代码锚点。
4. **已考虑的上下文**：哪些既有假设或前文定义适用，为何仍构成问题。
5. **证据**：推导、有效反例、TC↔SC 逐字对照、可重现的验证片段及实际结果，或来源链接与具体支持的命题。
6. **最小修改建议**：给可直接定位的建议文字，并写明修复位置（TC、SC 或 converter 规则）；保留作者教学意图。`inherited_from_tc` 与规则性 `conversion_error` 须注明「仅改 SC 会在重新转换时被覆盖」。
7. **影响与复核**：受影响例题、后续章节及 TC／EN 对应位置；引用 TC 报告的对应 id（若有，例如 `rigor-tc-ch02-001`）。记录复核支持、否定或尚有分歧及理由。
8. **处理状态**：`open`／`accepted`／`fixed`／`dismissed`，与 `confirmed` 等判断分开。只有实际修改且验证后才能写 `fixed`。

纯风格建议（含不影响理解的地区用语偏好）独立放在文末选用区，不列入数学错误统计。待验证问题独立列出，指出需要什么证据才能定案。计数从最终条目及其字段计算，不能以文字搜索命中次数计数。

## Converter 规则建议（有规则性转换错误时）

汇总建议新增的固定术语保护项或术语后处理项，每项附触发它的发现 id 与示例原文；仅为提案，是否修改 `tc-sc-ipynb-converter` / `tc-sc-converter` 由用户决定。

## 结尾

列出最重要的修订顺序（先 TC 根因、再 converter 规则、再 SC 单独修改）、未解分歧与尚未验证范围。没有高影响问题时如实陈述，不为凑报告制造问题。未授权修改教材时，建议文字仍只是提案。
